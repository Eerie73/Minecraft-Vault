## Structure

```
minecraft-vault/
│
├── mods/         # Game modifications
├── maps/         # World saves and custom maps
├── shaders/      # Shader packs
├── tools/        # Utilities (launchers, editors, etc.)
├── configs/      # Configuration files
├── docs/         # Notes and references
└── assets/       # Media files (screenshots, icons)
```
